# Guards

* [danger](danger.md) - destructive shell commands.
* [config-guard](config-guard.md) - changes to the harness configuration ask the person.
* [repo-rules](repo-rules.md) - the repo's own ask/deny rules from `rules` in .ai1/config.json.
* [issue-guard](../features/issue-report.md#private-data-check) - publishing private data to the public ai1 repo is refused (feature core).
* [test-guard](test-guard.md) - skipping, emptying, weakening or deleting tests asks the person (feature verify).
